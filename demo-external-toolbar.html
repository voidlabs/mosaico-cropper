A toolbar outside the cropper

Use the wheel over the image and watch Zoom update immediately. Drag to pan, drag the bottom handle to resize, or use Fit image to cycle through smart fitting.

Image controls

Keyboard: Tab to a control, use arrow keys on Zoom, and Enter or Space on buttons. This demo uses autoClose: false so focusing the external toolbar keeps editing active. With the default autoClose: true, leaving the cropper finalizes it.
